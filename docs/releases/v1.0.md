# PIC-tutor v1.0

`v1.0` freezes commit `e1faff5` as the first semantic project release. The canonical reader artifacts are the reviewed `v0.110` source edition:

- `dist/pic-tutor-v0.110.pdf` (275 pages)
- `dist/pic-tutor-v0.110.html`
- `dist/pic-tutor-v0.110.md`

## Included

- Chinese PIC tutorial from the kinetic model through WarpX implementation and validation boundaries.
- Source-grounded paths for particle pushers, deposition, field solvers, boundaries, AMR, diagnostics, and literature evidence.
- Local, bounded publisher-version comparisons for Esirkepov 2001 and Lee--Vay 2015. The publisher PDFs themselves are not included.

## Scope and Boundary

The tag freezes a reader-reviewable manuscript. It does not assert completion of open WarpX runtime gaps or resolve the repository-level third-party redistribution and license decision recorded in `docs/public-distribution-risk-register-v0.110.md`.

## Assets

Attach only the three `dist/pic-tutor-v0.110.*` reader artifacts to the GitHub Release. Do not attach `references/`, `runs/`, local audit outputs, or publisher PDFs.
