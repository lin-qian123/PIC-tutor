# RCYLINDER/RSPHERE species-rho decomposition observable

## Evidence

The archived 2-rank Esirkepov Langmuir plotfiles expose enough reader-side data to test a narrow identity independently of the radial `Er` and `divE-rho` checks:

$$
\rho = \rho_{\mathrm{electrons}} + \rho_{\mathrm{ions}}.
$$

The audit now checks all 81 current numbered frames for RCYLINDER shape 1/2/3/4 and RSPHERE shape 1/2/3/4: 648/648 frame checks pass. Using the largest participating field (`rho`, `rho_electrons`, or `rho_ions`) as the scale to avoid near-neutral cancellation, the maximum relative residual is `2.295e-16` and the maximum RMS relative residual is `9.802e-17`. The contract is generated by `scripts/audit_radial_rho_decomposition.py` and stored in `runs/stage-c-validation/radial-rho-decomposition-observable/contract.{json,md}`.

## Boundary

The RCYLINDER shape=1 case was rerun with only the diagnostic field list extended to include `rho_electrons` and `rho_ions`; its 81-frame series is included in the same check. The identity is a species decomposition observable, not a proof that radial `divE-rho` closes or that current deposition is correct. The existing radial charge matrix remains the authoritative record for those separate boundaries.
