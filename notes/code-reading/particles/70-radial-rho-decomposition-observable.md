# RCYLINDER/RSPHERE species-rho decomposition observable

## Evidence

The archived 2-rank Esirkepov Langmuir plotfiles expose enough reader-side data to test a narrow identity independently of the radial `Er` and `divE-rho` checks:

$$
\rho = \rho_{\mathrm{electrons}} + \rho_{\mathrm{ions}}.
$$

For RCYLINDER shape 2/3/4 and RSPHERE shape 1/2/3/4, the maximum relative residual is below `9.1e-15` and the RMS relative residual is below `4.3e-15`. The contract is generated by `scripts/audit_radial_rho_decomposition.py` and stored in `runs/stage-c-validation/radial-rho-decomposition-observable/contract.{json,md}`.

## Boundary

The RCYLINDER shape=1 archived plotfile contains `rho` and `Er`, but not `rho_electrons` or `rho_ions`; it is therefore recorded as an export boundary. The identity is a species decomposition observable, not a proof that radial `divE-rho` closes or that current deposition is correct. The existing radial charge matrix remains the authoritative record for those separate boundaries.
