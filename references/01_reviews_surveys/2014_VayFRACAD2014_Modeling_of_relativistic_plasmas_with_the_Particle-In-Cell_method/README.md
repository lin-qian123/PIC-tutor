## 书稿用途

该综述为第 4 章的 Boris/Lorentz-invariant pusher、第 6 章的 FDTD/NSFDTD/PSATD/PSTD 与 NCI 提供统一历史入口。论文使用 Warp 时代的实现和数值实验；本书不将其结果直接升级为当前 WarpX 函数级等价或 runtime PASS。
