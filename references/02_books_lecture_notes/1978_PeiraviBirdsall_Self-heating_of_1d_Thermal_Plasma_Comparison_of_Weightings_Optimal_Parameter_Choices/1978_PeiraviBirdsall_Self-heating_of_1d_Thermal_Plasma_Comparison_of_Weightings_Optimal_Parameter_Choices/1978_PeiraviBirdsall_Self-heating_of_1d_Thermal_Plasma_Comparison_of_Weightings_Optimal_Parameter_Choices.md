## ABSTRACT

Self-heating times of a one dimensional electrostatic

simulation thermal plasma are presented using zero order weightings (NGP), linear weighting (CIC-PIC), and quadratic spline weighting (QS). Maximum heating times are found to be along $v \frac { \Delta t } { \Delta x } \simeq \frac { 3 } { 2 }$ for NGP and $= \frac { 7 } { 2 }$ for CIC and QS . Considerable increase in self-heating time is achieved through truncation in k-space.

## I. INTRODUCTION

The self-heating (nonphysical) times for one-dimensional electrostatic thermal plasma are presented using zero order weighting (NGP), linear weighting (CIC-PIC), and quadratic spline weighting (QS) in a momentum conserving\* code, ESl of A. B. Langdon [1]. The self-heating time $\tau _ { h }$ is defined as the time taken for the thermal energy of the system to double. A 1d electrostatic thermal plasma model consistinq of a mobile electron species and immobile neutralizing ion background was used. For this system, this is the time in which the average kinetic energy of an electron increases by kT . The increase in energy is numerical in origin and stochastic in nature. It arises from fluctuations in the force due to the presence of finite grids in space and time. Thus, the self-heating times strongly depend on ∆t and ∆x .

A Maxwellian velocity loader with first and second moment correction was used [2].

R. W. Hockney [3] empirically obtained the self-heating times for a 2d plasma with ions and electrons using ${ \bar { \mathsf { T } } } _ { \mathsf { e } } = { \mathsf { T } } _ { \mathsf { i } }$ $m _ { i } / m _ { e } = 6 4$ , with further refinement by Hockney et al., [4]. We have added quadratic spline weighting and show self-heating times are longest for $\mathtt { v _ { t } } \frac { \Delta \mathtt { t } } { \Delta \mathtt { x } } \simeq \frac { 3 } { 2 }$ for NGP and $v _ { t } \ { \frac { \Delta t } { \Delta x } } \simeq \ { \frac { 1 } { 2 } }$ for CIC and QS.

## V COMPARISON OF SCHEMES; GAIN OF GOING TO A HIGHER ORDER ALGORITHM

These figures indicate that CIC heating times are as much as 70 times longer than NGP and that QS is as much as 650 times longer than NGP.

## VI INCREASE IN GAIN DUE TO SMOOTHING

## VII CONCLUSIONS

The self-heating times are longest for $v _ { t } \frac { \Delta t } { \Delta x } \simeq \frac { 3 } { 2 }$ for NGP and $v _ { t } \ { \frac { \Delta \mathbf { t } } { \Delta \mathbf { x } } } \simeq { \frac { 1 } { 2 } }$ for CIC and QS. Roughly speaking, quadratic spline heating times are one order of magnitude longer than for cloud-in-cell, whilecloud-in cell is one order of magnitude longer than nearest grid point, consideringboth gain in heating time and increase in cost. Smoothing by Fourier space truncation considerably increases the selfheating time and this increase is roughly proportional to

$$
\left( \frac { k _ { \mathrm { m a x } } } { k _ { 1 a s t } } \right) ^ { n + 1 }
$$

where n is the order of the weighting scheme, i.e., n=0 for NGP, n =1 for CIC, and n=2 for QS. Use of higher order algorithms is highly recommended, specially when k-space truncation is also used.

Quadratic spline weighting algorithm [6], [7] has been placed in the plasma simulation code ESl and as a check we present the dispersion for a cold plasma.

For momentum conserving codes. using quadratic splines, the shape factor S(k) and the κ (from ∇φ) and $x ^ { 2 }$ (from $\nabla ^ { 2 } \phi )$ operators are [8]

$$
\begin{array} { l c l } { \textsf { S } ( \mathbf { k } ) ~ = ~ \mathbf { d i f ^ { 3 } } ~ \left( \frac { \mathbf { k } \Delta \dot { \mathbf { x } } } { 2 } \right) } & { = } & { \left[ \frac { \sin { ( \mathbf { k } \Delta \times / 2 ) } } { \mathbf { k } \Delta \times / 2 } \right] ^ { 3 } } \end{array}\tag{1}
$$

$$
\begin{array} { r l } { \kappa ( \mathbf { k } ) = \mathbf { k } \mathrm { ~ d ~ i ~ f ~ } (  \mathbf { k } \Delta \mathbf { x } ) } & { { } = \mathbf { k } \frac { \textsf { \sin } ( \mathbf { k } \Delta \mathbf { x } ) } { \mathbf { k } \Delta \mathbf { x } } } \end{array}\tag{2}
$$

$$
k ^ { 2 } \left( \mathrm { \bf k } \right) ~ = ~ \mathrm { \bf k } ^ { 2 } { \sf d i f } ^ { 2 } \left( \frac { \mathrm { \bf k } \Delta \bf x } { 2 } \right) ~ = ~ \mathrm { \bf k } ^ { 2 } \left[ \frac { \sin { \left( \mathrm { \bf k } \Delta \times / 2 \right) } } { \mathrm { \bf k } \Delta \times / 2 } \right] ^ { 2 } ~ .\tag{3}
$$

The dispersion equation for a cold plasma is, using $k _ { p } \equiv k - p k _ { g } , k _ { g } \equiv \frac { 2 \pi } { \Delta x }$

$$
\frac { \omega ^ { 2 } } { \omega _ { _ { \mathrm { P } } } ^ { 2 } } = \frac { 1 } { \kappa ^ { 2 } ( { \bf k } ) } \sum _ { \mathrm { ~ \scriptsize ~ { ~ p ~ } ~ } } { \sf k } _ { \mathrm { ~ \scriptsize ~ { ~ p ~ } ~ } } \kappa ( { \bf k } _ { \mathrm { ~ \scriptsize ~ { ~ p ~ } ~ } } ) \mathbb { s } ^ { 2 } ( { \bf k } _ { \mathrm { ~ \scriptsize ~ { ~ p ~ } ~ } } ) .\tag{4}
$$

Using Eqs. (1,2,3) in (4) we obtain

$$
\begin{array} { r l } { \frac { \omega ^ { 2 } } { { \bf \omega } _ { \bf p } ^ { 2 } } } & { = \frac { 1 } { \left. \mathrm { ~ k ~ } ^ { 2 } \mathrm { ~ d ~ i ~ f ~ } \left( \mathrm { k ~ } \Delta \times / 2 \right) \right. } \quad \sum _ { \mathrm { ~ p ~ } } \mathrm { ~ k ~ } _ { \mathrm { ~ p ~ } } ^ { 2 } \mathrm { ~ d ~ i ~ f ~ } ( \mathrm { k ~ } _ { \mathrm { ~ p ~ } } \Delta \times ) \mathrm { ~ d ~ i ~ f ~ } ^ { 6 } ( \mathrm { k ~ } _ { \mathrm { ~ p ~ } } \Delta \times / 2 ) } \end{array}\tag{5}
$$

$$
= \frac { 2 ^ { 4 } \sin ^ { 4 } ( k \Delta x / 2 ) \sin ( k \Delta x ) } { \Delta x ^ { 5 } } \sum \limits _ { p } \frac { 1 } { k _ { p } ^ { 3 } }\tag{6}
$$

$$
= ~ \left( \frac { 2 } { \Delta \times } \right) ^ { 5 } ~ \sin ^ { 5 } ( k \Delta x / 2 ) \cos ( k \Delta x / 2 ) \sum _ { \mathrm { ~ p ~ } } \frac { 1 } { k _ { \mathrm { ~ p ~ } } ^ { \mathrm { ~ 5 ~ } } } .\tag{7}
$$

Using the identity

$$
\begin{array} { r l r } { \sum \frac { 1 } { ( { \bf k } - { \bf p } { \bf k } _ { \mathrm { g } } ) ^ { 2 } } } & { { } \equiv } & { \left[ \left( \frac { 2 } { \Delta \times } \right) \sin ( { \bf k } \Delta \times / 2 ) \right] ^ { - 2 } } \\ { { \bf p } ^ { ( { \bf k } - { \bf p } { \bf k } _ { \mathrm { g } } ) ^ { 2 } } } \end{array}\tag{8}
$$

and differentiating three times successively, we get at each step

$$
\begin{array} { r l r } { \sum _ { \mathsf { \Delta } } \frac { 1 } { ( { \bf k } - { \mathsf { p k } } _ { \mathsf { g } } ) ^ { 3 } } } & { = } & { \dot { \cos } \left( { \bf k } \Delta { \bf x } / 2 \right) \left[ \left( \frac { 2 } { \Delta \mathsf { x } } \right) \dot { \sin } \left( \dot { \bf k } \Delta { \bf x } / 2 \right) \right] ^ { - 3 } } \\ & { } & \end{array}\tag{9}
$$

$$
\sum _ { \mathfrak { p } } \frac { 1 } { ( \mathbf { k } - \mathfrak { p } \mathbf { k } _ { \mathfrak { g } } ) ^ { 4 } } = \frac { 1 } { 3 } \left( \frac { \Delta \times } { 2 } \right) ^ { 2 } \left[ \left( \frac { 2 } { \Delta \times } \right) \sin { ( \mathbf { k } \Delta \times / 2 ) } \right] ^ { - 2 }
$$

$$
\therefore + \cos ^ { 2 } ( k \Delta x / 2 ) \left[ \left( \frac { 2 } { \Delta x } \right) \sin ( k \Delta x / 2 ) \right] ^ { - 4 }\tag{10}
$$

$$
\begin{array} { r c l } { \displaystyle \sum _ { \mathfrak { p } } \frac { 1 } { ( \mathsf { k } - \mathsf { p k } _ { \mathfrak { g } } ) ^ { 5 } } } & { = } & { \displaystyle \cos \left( \mathsf { k } \Delta \times / 2 \right) \left[ \left( \frac { 2 } { \Delta \times } \right) \mathsf { s i n } \left( \mathsf { k } \Delta \times / 2 \right) \right] ^ { - 5 } } \\ & & { . } & { \displaystyle \left[ \frac { 2 } { 3 } \mathsf { s i n } ^ { 2 } \left( \mathsf { k } \Delta \times / 2 \right) \right. + \left. \cos 2 \left( \mathsf { k } \Delta \times / 2 \right) \right] ^ { - 5 } } \end{array}\tag{11}
$$

$$
\sum _ { \textbf { \textsc { p } } \textbf { \textsc { k } } _ { \mathrm { p } } ^ { 5 } } \frac { 1 } { \textbf { \textsc { s o } } _ { \mathrm { { } } } ! } \sum _ { , \textbf { \textsc { i } } , \textbf { \textsc { i } } _ { \mathrm { { } } } } \left( \frac { 2 } { \Delta \times } \right) ^ { \textbf { \textsc { s i n } } \left( \mathbf { k } \Delta \times / 2 \right) } \bigg ] ^ { - 5 } \bigg [ \frac { 2 + \cos ^ { 2 } \left( \mathbf { k } \Delta \times / 2 \right) } { 3 } \bigg ] .\tag{12}
$$

Thus, the dispersion equation reduces to

$$
\begin{array} { r l r } { \omega _ { \mathrm { p } } ^ { 2 } } & { { } = } & { \cos ^ { 2 } \left( \mathrm { k } \Delta \times / 2 \right) \left( \frac { 2 + \cos ^ { 2 } \left( \mathrm { k } \Delta \times / 2 \right) } { 3 } \right) . } \end{array}\tag{13}
$$
