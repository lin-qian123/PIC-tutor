# Vay 2008 relativistic pusher reference

## Bibliographic status

- Title: Simulation of beams or plasmas crossing at relativistic velocity
- Author: J.-L. Vay
- Venue: Physics of Plasmas 15(5), 056701 (2008)
- DOI: `10.1063/1.2837054`

This is the Vay pusher reference used by Chapter 4 and by WarpX's `UpdateMomentumVay.H` source mapping.

## Local asset status

The directory contains a 7-page full-text PDF, MinerU Markdown, 38 extracted images and a Chinese walkthrough. The local package is checked by `scripts/audit_pusher_paper_asset_contract.py`.

The package supports the frame-consistency argument, the explicit `gamma` root, the bounded Darwin-lite field-solver context and the Appendix B gyroradius condition. It does not imply that WarpX has a dedicated runtime reproduction of every paper figure.
